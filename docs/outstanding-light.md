# Lightweight outstanding centre / 轻量待清中心

The sidebar is a list first. It does not introduce another editor, client directory or workflow state.

## Daily use / 日常操作

- Open items appear by default. Add uses the existing guarded form and Save and add another flow.
- Use Search and filter to reveal search, open/cleared/all scope, workstream and configured status filters. Folding the controls does not reset filters; the active count and reset action remain visible.
- More contains the existing client follow-up draft and status settings. Escape closes the disclosure and returns focus to its trigger.
- Each item shows its full title, module, a note indicator where applicable and one readable status chip. The chip is a native select with a fully wrapped visible label; no binary completion shortcut or status definition changes.
- Expand a title for its full note, source link and Edit. Delete is inside item More and still requires confirmation. Only one item detail is open at a time. All controls work without hover.
- Ordinary projects show company/period context once. Holding lists are grouped by source type and annual ID, not display names or item IDs. Each source header contains its company and full periods.
- Saving or opening an item from reports/other views resets obstructing filters, expands the item and focuses it. Cancelling an edit keeps the existing draft protection and return focus. Closing/deleting an item retains a usable adjacent control or filter trigger.

## Boundaries / 边界

Disclosure and filtering state is in memory only. No business schema, entity/engagement identifiers, group snapshots, archive semantics, status definitions, audit/tax calculations or persistence format changes. Notes remain readable on expansion and are not searched or automatically included in client drafts. Read-only sources expose no edit/delete/status-write controls.
